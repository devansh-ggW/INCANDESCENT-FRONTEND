INCANDESCENT — WINDOWS QUICK START

1. Download the real installer from:
   https://github.com/devansh-ggW/INCANDESCENT-FRONTEND/releases/download/v1.0.0/INCANDESCENT-Setup.exe

2. Run INCANDESCENT-Setup.exe.

3. Keep Ollama installed. This installer does not install Ollama.

4. The setup checks for qwen3.5:2b and can download it through Ollama if missing.

5. Do not use the repository's Code > Download ZIP archive to get the executable.
   Download the installer directly from Releases instead.

Support / release files:
https://github.com/devansh-ggW/INCANDESCENT-FRONTEND/releases/tag/v1.0.0

The initial release targets 64-bit Windows 10 and later. ARM64 is best-effort via x64 emulation; 32-bit Windows and Windows 7/8/8.1 are not supported.
